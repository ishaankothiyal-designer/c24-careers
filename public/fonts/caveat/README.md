# Caveat

Variable font from the Google Fonts Caveat distribution, retrieved 15 November 2026. Used at weight 500 for the letter body in both the canvas and readable HTML fallback. The signature keeps its separate typeface.

Source: https://github.com/google/fonts/tree/main/ofl/caveat
Font: https://raw.githubusercontent.com/google/fonts/main/ofl/caveat/Caveat%5Bwght%5D.ttf
License: SIL Open Font License 1.1, included as OFL.txt. Self-hosted; no runtime third-party font request.
